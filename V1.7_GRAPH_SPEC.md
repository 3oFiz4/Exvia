# v1.7 timestamp-total cumulative box plot specification

This is the rendering/data contract used by `Statistics.cumulativeBoxSeries()` and `CumulativeBoxPlotView`.

## 1. Input normalization

For a numeric key `K` and inferred date key `D`:

1. Parse `row[D]` into an epoch timestamp.
2. Parse `row[K]` into a number.
3. Omit a row from this graph if either parse fails.
4. Group remaining rows by the exact parsed timestamp.
5. For each timestamp `t`, define the observation:

   `O[t] = sum(row[K] for every row whose parsed D == t)`

For the money key (`PRICE`, `amount`, etc.), `O[t]` is therefore the total PRICE at that datetime.

No missing datetime is synthesized. Timestamps stay at their real positions on the X axis.

## 2. Cumulative statistics

Sort distinct timestamp observations chronologically:

`O[0], O[1], ..., O[i]`

At point `i`, calculate statistics from the cumulative prefix `O[0..i]`:

- mean
- median / Q2
- Q1
- Q3
- population standard deviation
- IQR = Q3 - Q1
- Tukey lower fence = Q1 - 1.5 * IQR
- Tukey upper fence = Q3 + 1.5 * IQR
- cumulative outliers = prefix observations outside those fences

Whiskers are `mean - STDV` to `mean + STDV`.

## 3. Direction state

For point `i > 0`:

- `O[i] > O[i-1]` => UP => green
- `O[i] <= O[i-1]` => DOWN => red

For `i == 0`, use NEUTRAL because no previous observation exists.

Missing calendar dates do not alter this comparison. The previous value means the previous *available timestamp observation*.

## 4. Rendering contract

Each timestamp is one vertical mini-boxplot:

- Q1..Q3: fully opaque box, no transparency.
- Box and box border: direction color.
- Mean ± 1σ whisker and caps: same direction color as the box.
- Median: solid horizontal line across the box; high-contrast near-white tint based on direction.
- Mean: dotted horizontal line across the box; same contrast family as median.
- Actual timestamp observation `O[t]`: filled blue rectangle with a light outline.
- Tukey outliers: hollow amber circles.
- Selected point: blue outline around the full rendered vertical extent.

Semantic colors currently used by the chart:

- UP green: `rgb(52, 199, 89)`
- DOWN red: `rgb(247, 35, 35)`
- Actual observation blue: `rgb(61, 139, 255)`
- Outlier amber: `rgb(255, 179, 0)`
- First/neutral box: current theme axis/muted color

The app theme still controls background, grid, axis, and base text colors.

## 5. X axis / missing dates

- X positions use actual epoch timestamps, not point indices.
- If a date/time is absent from the data, there is simply a larger horizontal gap.
- The app does not insert zero-valued or synthetic observations.
- Visible datetime labels wrap as two lines: `d/M/yy` then `HH:mm`.
- Labels are thinned automatically when too many points are visible.

## 6. Interaction

- Pinch: zoom up to 40x.
- Drag: pan.
- Double tap: reset viewport.
- Tap a box: select nearest timestamp and display:
  - datetime
  - aggregated timestamp total
  - number of raw rows merged into that timestamp
  - cumulative timestamp observation count
  - Q1
  - median
  - mean
  - Q3
  - standard deviation
  - cumulative outlier count
  - whether the current timestamp total is an outlier

## 7. Example

Raw rows:

```text
3/7/26 @ 10:00   PRICE 5
3/7/26 @ 10:00   PRICE 7
3/7/26 @ 11:00   PRICE 2
3/7/26 @ 15:30   PRICE 20
```

Timestamp observations:

```text
10:00 -> 12
11:00 -> 2
15:30 -> 20
```

Cumulative prefixes:

```text
10:00 -> [12]
11:00 -> [12, 2]
15:30 -> [12, 2, 20]
```

Direction colors:

```text
10:00 -> neutral
11:00 -> red   (2 <= 12)
15:30 -> green (20 > 2)
```
