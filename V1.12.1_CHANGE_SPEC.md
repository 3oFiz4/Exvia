# Exvia v1.12.1 change specification

## 1. Android touch ownership

`PlotWebRuntime` reserves the parent touch stream whenever a gesture begins in a plot WebView. `ACTION_UP` and `ACTION_CANCEL` release the parent. This prevents a vertical D3 pan from moving the outer Android ScrollView at the same time.

WebView long-click handling, haptic feedback, and browser touch-callout selection are disabled.

## 2. Stable tooltip interaction

The D3 history chart replaces hover-only tooltips with a tap-duration and movement-threshold interaction:

- maximum movement: 10 CSS pixels;
- maximum tap duration: 900 ms;
- a qualifying tap pins the tooltip;
- tapping the same node toggles it closed;
- background tap and zoom start close it.

Observable accumulation and normal plots receive a transparent SVG tap inspector. It converts the tap coordinate to the plot's X domain, selects the nearest datum, and pins a shared Exvia tooltip.

## 3. Tooltip colors

`PlotTheme` adds:

```text
selection
tooltipBackground
tooltipText
tooltipBorder
```

These values are persisted in SharedPreferences, serialized into the synchronized Exvia config, available to custom scripts, and exposed through color-picker configuration inputs.

The WebView runtime sets CSS variables for the tooltip surface and overrides Observable Plot's generated tooltip class.

## 4. Responsive layout

`WebPlotView` defers first render until the borrowed WebView has non-zero measured dimensions. Layout-size changes cause a re-render. The JavaScript runtime also observes viewport-size changes as a secondary safeguard.

This removes the previous fallback-width behavior that could leave a landscape chart at roughly 360 px wide.

## 5. X spacing

History no longer expands its date domain by 6%. It uses the exact first/last domain and reserves only 5–9 pixels inside the range. A single timestamp uses a small synthetic half-span so the scale remains valid.

Plot margins are reduced:

```text
History: left 50, right 8, top 18, bottom 52
Observable: left 48, right 8, top 12, bottom 40
```

## 6. History density

Maximum history box width is reduced to 10 px before zoom. Whiskers, center lines, outlier circles, the observation path, and the blue rhombus are all reduced proportionally.

Because the complete D3 mark group is transformed, these elements scale naturally during zoom.

## 7. Observable zoom

`helpers.attachZoom` now transforms the complete returned figure using GPU-backed `translate3d + scale`, fixed transform origin, and no max-width restriction. Observable SVG symbols therefore scale visually with zoom rather than retaining a fixed apparent size.

## 8. Version and omissions

```text
versionName = 1.12.1
versionCode = 14
```

The archive omits both logo files and all obsolete native plotting engines.
