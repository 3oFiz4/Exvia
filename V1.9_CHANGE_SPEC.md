# v1.9 change specification

## Help / tooltips

- Config input hints expose their persistent/config key.
- Statistical, Financial, and Configuration text: hold ~2000 ms for contextual PopupWindow help.
- Tooltip dimensions are content-driven with a 300dp max width.
- Tooltip border uses Primary; background uses Tertiary; text uses Senary.
- If anchor center is in top half of display, tooltip opens below. Otherwise it opens above.
- Ordinary config inputs add a right-edge `ⓘ` immediate-help control.

## Filter snippets

- Filter syntax input hold threshold: ~1000 ms.
- Opens local snippet manager.
- CRUD: select/create/edit/remove.
- Selecting copies the stored query into the current filter input.
- Snippets are persisted in app SharedPreferences as JSON metadata.
- Enabling Filter continues to replace both Table and Stat source rows with the matching subset.

## Repository bootstrap

Condition:

1. PAT exists.
2. Bootstrap question has not previously been answered in this installation.

Question: existing initialized repository?

- Yes: mark bootstrap question answered and continue/load existing config.
- No: prompt for username, repository, branch, folder, default JSON filename.
- Create a private repository, create requested branch when it differs from GitHub's initialized default, create `<folder>/<default file>` containing `[]`, persist resulting config, then reload.

## Plot visibility

Each plot is a nested Stat accordion:

- History
- Accumulation
- Normal distribution

Closed: `+ Title`; open: `− Title`.

`stats.plot_columns` is a comma/newline-separated key list. Initial default is `price`; matching is case-insensitive. Empty saved list means no columns are plotted.

## Finance report configuration

`finance.columns` is a comma/newline-separated key list. Initial default is `price`; matching is case-insensitive. Empty saved list disables Personal finance.

Groups, in priority order:

1. Core
2. Expense
3. Income
4. Behavior
5. Liquidity

All metric name/value rows receive help tooltips.

## Custom metrics

Settings accordion: `Custom metric`.

Metric definition:

- id
- name
- JavaScript function body
- enabled flag in persisted model

Stat accordion: `Custom`.

Execution context uses the currently visible TableData, therefore filtering is automatically inherited.

Available JS symbols:

- `rows`
- `keys`
- `dateKey`
- `moneyKey`
- `tickerKey`
- `tagsKey`
- `num(value)`

Evaluation is started by Kotlin using an isolated Android WebView JavaScript runtime. No JavaScript bridge is installed; file/content access and DOM storage are disabled; network loading is blocked.

## Dialogs / colors

- Alert dialog window fill = current Tertiary.
- Alert dialog border = current Primary.
- Dialog action buttons use compact no-idle-border styling.
- Color configuration rows add a left-edge live swatch.
- Swatch click opens an RGB picker and writes selected value as `#RRGGBB`.

## Retained plotting behavior

- History graph first aggregates numeric rows sharing an exact timestamp.
- Timestamp totals feed cumulative Q1/Q3/median/mean/STDV snapshots.
- Green box when current total > previous total; red otherwise; first neutral.
- Actual timestamp total = blue wide rhombus.
- Outlier = tiny red hollow circle.
- 40%-opacity blue observation path.
- Real missing dates remain horizontal time gaps.
- Extra X padding prevents first/last visual clipping.
