# v1.8 change specification

## Cumulative box timeline

Input rows are grouped by exact parsed datetime and numeric values are summed per timestamp before cumulative statistics are computed.

At timestamp `t_i`:

- observation = sum of numeric values whose parsed datetime equals `t_i`
- cumulative sample = observations from `t_0 ... t_i`
- box bottom/top = cumulative Q1/Q3
- solid internal line = cumulative median
- dotted internal line = cumulative mean
- whisker = cumulative mean ± 1 population standard deviation
- tiny red hollow circle = cumulative Tukey outlier
- blue wide rhombus = current timestamp observation
- translucent blue polyline (40% alpha) = observation sequence
- box/whisker green iff current observation > previous observation, otherwise red; first is neutral

X-axis uses real epoch timestamps, keeps missing-time gaps, wraps date/time labels, and includes 5.5% domain padding on both sides to avoid clipping first/last glyphs.

## Additional money plots

For the inferred money key:

- Cumulative money plot = running sum of grouped timestamp totals
- Normal distribution plot = fitted population normal PDF of numeric values in the currently displayed dataset, with sample rug marks

Both are interactive with pinch zoom, drag pan, and double-tap reset.

## Filtering

Compact UI directly below Amend:

- one-line SQLite-style query field
- Filter ON/OFF control
- active filter has border; inactive filter has none

Filter output becomes the displayed TableData passed to Table and Stat. CRUD still references original rows via their original indices/JSON snapshots.

Supported WHERE subset: boolean logic, parentheses, comparisons, LIKE, IN, IS NULL, REGEX/REGEXP function and operator forms. This is a safe evaluator, not arbitrary SQL execution.

## Interaction/UI
