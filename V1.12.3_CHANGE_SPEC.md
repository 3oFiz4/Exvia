# Exvia v1.12.3 change specification

## 1. Problem corrected

The previous implementation zoomed by reducing the SVG `viewBox`. This magnified every SVG user unit. Therefore a box that was 10 px wide at 100% became approximately 20 px wide at 200%; marker radii, text, strokes, and grid lines grew as well.

That behavior was geometric magnification, not the required chart/data zoom.

## 2. Semantic zoom model

Zoom now modifies data scales rather than SVG dimensions.

For each D3 zoom transform `T`:

```javascript
visibleX = T.rescaleX(baseX)
visibleY = T.rescaleY(baseY)
```

Marks are redrawn at positions derived from `visibleX` and `visibleY`. Fixed visual dimensions remain literal CSS/SVG pixel values.

### Fixed dimensions

- history box width;
- whisker and line stroke widths;
- median/mean line thickness;
- blue observation-rhombus width and height;
- red outlier radius;
- axis font size;
- grid stroke width;
- interaction hit width.

### Data-scaled dimensions

- X/Y positions;
- timestamp spacing;
- quartile vertical range;
- standard-deviation whisker length;
- line-path geometry;
- visible domains and axis labels.

## 3. History plot

The History plot retains one SVG and updates:

- X and Y axes;
- Y grid;
- observation line;
- snapshot-group positions;
- box Y/height;
- median and mean Y positions;
- whisker endpoints;
- outlier Y positions;
- observation-rhombus Y position.

No SVG group or `viewBox` is magnified.

## 4. Observable Plot graphs

Accumulation and Normal Distribution use Observable Plot as before. During zoom, Exvia re-renders the plot using transformed X/Y domains. Rendering is throttled to one update per animation frame.

This preserves constant Plot mark radii and stroke widths while changing the visible data region.

## 5. Custom plots

`helpers.attachZoom` now accepts a redraw callback. A generic arbitrary SVG cannot safely infer whether a rectangle is a fixed-size node, a data bar, a heatmap cell, or a layout surface, so custom scripts must specify their semantic redraw when they need zoom.
