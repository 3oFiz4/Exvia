# Exvia v1.12 change specification

## 1. Plot engine replacement

Removed the three native plotting implementations:

```text
CumulativeBoxPlotView.kt
InteractiveLinePlotView.kt
CustomPlotEngine.kt
```

All plots are now rendered inside reusable WebViews through:

```text
PlotWebRuntime.kt
WebPlotView.kt
app/src/main/assets/plot_runtime/index.html
app/src/main/assets/plot_runtime/runtime.js
```

The runtime pins D3.js 7.9.0, Observable Plot 0.6.17, and Arquero 8.0.3.

## 2. Runtime lifecycle and performance

- The first Android frame is allowed to draw, then one runtime WebView is initialized from `MainActivity.onCreate`.
- After that WebView finishes loading the JavaScript modules, two chart WebViews are pre-warmed.
- Chart WebViews share Android WebView's persistent HTTP cache.
- A dedicated runtime is reused serially for custom metrics.
- Chart WebViews are borrowed from and returned to a small pool.
- Plot accordion content is created only when first opened.
- Closing an accordion suspends/recycles descendant chart WebViews.
- One effective JSON serialization is shared by all custom plots and metrics during a Stat render pass.
- JavaScript syntax highlighting is debounced and remains a lightweight native `EditText`, not another WebView.
- Hardware acceleration is explicitly enabled in the manifest and on pooled chart WebViews.
- Main-frame navigation, JavaScript-created windows, mixed content, file-URL universal access, and content access are disabled.

## 3. Default history plot

D3.js performs exact-datetime aggregation, cumulative statistics, Tukey outlier detection, directional color selection, SVG drawing, tooltip interaction, and zoom/pan.

The existing business logic is preserved:

```text
observation(t) = sum of all values at the exact datetime t
box(t)        = cumulative Q1 through Q3 of observation totals up to t
median(t)     = solid line
mean(t)       = dotted line
whiskers(t)   = mean ± population standard deviation
outlier       = value below Q1 - 1.5×IQR or above Q3 + 1.5×IQR
```

Direction:

```text
current > previous  → positive/green
current <= previous → negative/red
first point         → neutral
```

## 4. Observable Plot charts

`renderAccumulation` uses Observable Plot for the timestamp-level running sum.

`renderNormal` uses Observable Plot for the fitted normal PDF and observation ticks.

## 5. Plot theme

`PlotTheme` is persisted separately from `ThemePalette` and synchronized in `.exvia-config.json`.

Default values:

```text
background  #000000
surface     #11151C
text        #EDEDED
muted       #7D7D7D
grid        #1F1F1F
axis        #7D7D7D
positive    #34C759
negative    #F72323
observation #3D8BFF
outlier     #F72323
center      #FFFFFF
accent      #A970FF
```

Ayu preset values are also available.

## 6. Custom plots

`CustomPlotDefinition` now persists:

```text
id
name
script
engine
enabled
```

Old v1.11 axis-source definitions are migrated automatically to an Observable Plot script when loaded.

The custom script may return a DOM node, return a D3 selection, or append to `context.container`.

## 7. Custom metrics

`CustomMetricEngine` no longer creates and destroys one WebView per metric. It evaluates scripts through the shared pre-warmed runtime.

Both custom metrics and custom plots receive:

```text
context, jsonFile, d3, Plot, aq, theme, helpers
```

## 8. Editors

`JavaScriptCodeEditor` gives both custom metric and custom plot scripts an Ayu dark background with native syntax highlighting for JavaScript keywords, strings, numbers, comments, and Exvia globals.

## 9. Logo handling

The v1.12 archive excludes both logo files. Gradle uses an existing logo if present and otherwise falls back to Android's default icon. Extracting this archive over the user's project therefore does not overwrite their logo asset.

## 10. Compatibility

The Android application ID remains:

```text
com.example.exp_tracker
```

Existing installations can therefore be upgraded when signed with the same key.
