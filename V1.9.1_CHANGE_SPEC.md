# exp_tracker v1.9.1 change specification

## Tooltip fix

- Statistical, Financial, Configuration labels: tooltip threshold remains 2000 ms.
- A tooltip is emitted only while the same stationary press remains active.
- `ACTION_UP`, `ACTION_CANCEL`, movement beyond Android touch slop, or a second pointer cancels the pending callback.
- Non-input text views consume the gesture so release events cannot be lost; a short release replays the normal click with `performClick()`.
- `EditText` keeps native touch handling.
- A completed tooltip hold consumes the release so an accordion does not also toggle.
- The 1000 ms Filtering Snippet hold uses the same active/cancellation principle.

## Filtering snippet examples

Built-in read-only templates are displayed above user-saved snippets:

1. July 2026 dates
   `SELECT * WHERE REGEXP(date, '^[0-9]{1,2}/7/26(?:\s*@.*)?$')`
2. Price at least 50
   `SELECT * WHERE price >= 50`
3. Income / explicit +PRICE
   `SELECT * WHERE REGEXP(price, '^\+')`
4. Food-like descriptions
   `SELECT * WHERE REGEXP(description, '(?i)food|lunch|dinner|restaurant|meal')`

Selecting an example copies it into the compact filter input; examples are not mixed into the user's persisted CRUD snippet collection.

## JavaScript custom metric host

v1.9.1 removes the old injected helper variables from the evaluator. The only host object is:

```js
jsonFile = {
  name: "2026-07.json",
  content: "[...]"
}
```

- `name` is the selected JSON filename.
- `content` is the current effective Table/Stat subset serialized as JSON text.
- Rows are reconstructed from each source row's `originalJson` when possible so source JSON value types are retained.
- Filtering therefore continues to affect custom metrics.
- Scripts parse their own schema with `JSON.parse(jsonFile.content)`.
- No Java bridge, file/content access, DOM storage, or network loading is enabled in the WebView runtime.

## Built-in custom metric examples

Seven non-enabled templates appear in Settings → Custom metric. `Use` opens an editable copy and does not alter the template itself.

- 90th Percentile Expense
- Largest Spending Day
- Longest No-Spend Streak
- Weekend Spending Ratio
- Expense Category Concentration (HHI)
- Top 10% Expense Share
- Average Spend per Active Day

These examples intentionally demonstrate financial calculations that are not already part of the built-in Core / Expense / Income / Behavior / Liquidity metric groups.
