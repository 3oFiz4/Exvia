# Exvia v1.13 change specification

## 1. Named custom UI themes

- Adds `NamedUiTheme(id, name, palette)`.
- The UI theme selector combines built-in presets with user-created named themes.
- **Save current as theme** captures all six editable UI palette colors.
- Theme names must be non-empty and unique case-insensitively.
- **Delete selected** removes custom themes only.
- The active theme ID and full custom-theme list persist locally and are included in the synchronized Exvia configuration.

## 2. Named custom plot themes

- Adds `NamedPlotTheme(id, name, theme)`.
- The plot-theme selector combines Black, Ayu, and named custom themes.
- Saving captures all 16 plot colors.
- Custom themes can be selected and deleted; built-ins are protected.
- Active plot-theme ID and definitions are synchronized in `Financial/.exvia-config.json`.

## 3. Additional filtering snippets

Six snippets were added:

- August 2026 dates;
- morning timestamps;
- price range 10–100;
- transport-like descriptions using REGEXP;
- food/non-cash tags using REGEXP;
- missing descriptions.

This produces 10 built-in filtering examples in total.

## 4. Additional custom metrics

Six JavaScript templates were added:

- Expense Gini Coefficient;
- 95th Percentile Daily Spend;
- 7-Day Expense Momentum;
- Late-Night Spending Ratio;
- Small-Purchase Leakage;
- Expense Category Entropy.

This produces 13 built-in custom metric examples in total.

## 5. Additional custom plots

Five JavaScript templates were added:

- Observable monthly income vs expense;
- Observable rolling expense average;
- Observable expense histogram;
- D3 category treemap;
- D3 expense beeswarm.

This produces 10 built-in custom plot examples: six Observable Plot examples and four D3 examples.

## 6. Compatibility

- Existing preset IDs and stored palette values remain supported.
- Existing custom metrics, custom plots, snippets, settings, semantic zoom, and repository synchronization remain unchanged.
- Logo assets remain intentionally omitted.
