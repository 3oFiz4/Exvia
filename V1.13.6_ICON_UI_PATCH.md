# Exvia v1.13.6 — Icon/UI display patch

Version remains `1.13.6` / versionCode `23`.

## Icon assets

All UI icons are loaded from `app/src/main/assets/icons/`.

The patch intentionally supplies empty `.png` placeholders rather than embedding a third-party icon set. They are safe to replace directly with rounded-outline monochrome PNGs. Runtime tinting applies the current `$primary` color through Android's drawable color filter.

`UiIconSupport.load()` catches missing-file and decode failures and returns `null`; no icon failure can prevent the surrounding UI from rendering.

## Display modes

`UiIconMode` provides:

- `ICON_ONLY`
- `TEXT_ONLY`
- `ICON_AND_TEXT`

Default: `ICON_AND_TEXT`.

Setting location: `Settings → Interface → Icon / text display`.

The mode is saved in SharedPreferences and synchronized as `display.iconMode` in `.exvia/.exvia-settings.json`.

## Components covered

The shared icon renderer is applied to:

- `styledButton(...)` controls across Table, Stat, Files, Settings, Git workflow, CRUD, managers, and pagination;
- title-row `Git`, `Re-sync`, and Settings actions;
- Table Filtering/Flagging controls;
- accordion/section headers, with start icon plus Primary-tinted up/down chevron;
- Custom Stat and built-in-example action controls such as Edit, Use, and Delete;
- Settings/configuration Spinners, including themes, plotting engines, Custom Accordion group selection, Git amend mode, notification event, report type, and formula language.

For dropdowns, the collapsed view follows the chosen icon/text mode. Expanded choices always show text so an Icon-only preference cannot make the option list ambiguous.

## Asset naming

Static labels are converted to context-based PascalCase names, for example:

```text
Git                -> Git.png
Re-sync            -> Resync.png
Table              -> Table.png
Imaginary fields   -> ImaginaryFields.png
Save settings and reload -> SaveSettingsAndReload.png
SQLite file scripts -> SQLiteFileScripts.png
```

Special dynamic controls use stable names such as `Filtering.png`, `Flagging.png`, `Revert.png`, `Toggle.png`, `ChevronUp.png`, and `ChevronDown.png`.

The full manifest is maintained in `app/src/main/assets/icons/README.md`.
